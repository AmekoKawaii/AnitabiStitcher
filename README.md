# AnitabiStitcher

**Anitabi Stitcher** is a toy project by Ameato. You can select two images, enter some text descriptions, and then click "Stitch" to generate a vertically stitched image with the text included. It's suitable for creating comparison images for anime pilgrimage. **_Currently supports Chinese only._**

**Anitabi Stitcher**是Ameato的一个玩具项目，你可以选择两张图片，然后输入一些文字描述，最后点击拼接来得到一张上下拼接，并带有文字描述的图片，适合用来制作动画圣地巡礼的对比图，**_目前仅支持中文_**。
